# 폐교 : 서아

문 닫은 학교에 갇힌 남학생이 메모 3장을 모아 탈출하는 3D 로우폴리 공포 게임 (Three.js, 어깨너머 3인칭).

▶ 플레이: https://jkspawn.github.io/ghostgirlinschool/

⚠ 깜짝 놀라는 장면과 큰 소리가 있습니다. 헤드폰 권장. 키보드·마우스가 필요합니다.

## 조작
| 키 | 동작 |
|---|---|
| 마우스 (또는 ← →) | 둘러보기 |
| W A S D | 이동 |
| Shift | 달리기 (발소리가 커짐) |
| F | 손전등 켜기/끄기 |
| E | 줍기 / 사물함에 숨기 / 현관문 |

- 메모 3장은 매번 다른 교실에 놓입니다. 다 모으면 중앙현관 자물쇠가 풀립니다.
- 손전등을 비추면 그녀가 느려지고, 계속 비추면 사라집니다. 대신 배터리가 빨리 닳고, 불빛 때문에 더 멀리서 들킵니다.
- 복도 사물함에 숨으면 따돌릴 수 있습니다. 숨는 걸 들키지만 않는다면.
